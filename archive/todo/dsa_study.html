Plan and Priority

Plan 1

  • Fundamentals & Data Structures: Review your primary language’s syntax, data types, control structures, and essential data structures (arrays, linked lists, stacks, queues, trees, graphs)

  • Algorithms & Complexity: Practice sorting and searching techniques while understanding Big O notation to analyze efficiency.

  • Object-Oriented Programming & Design Patterns: Deep dive into OOP principles (encapsulation, inheritance, polymorphism, abstraction) and study common design patterns like Singleton, Factory, and Observer.

  • HIGH: Arrays, Strings, Hash Tables, Linked Lists, Stacks/Queues, Trees (BST, Heaps), Graphs (BFS/DFS), Sorting, Binary Search, Two Pointers, Sliding Window, Recursion

  • MEDIUM: DYNAMIC PROGRAMMING (BASICS), GREEDY ALGORITHMS, TRIES, BACKTRACKING

  • LOW: ADVANCED GRAPH ALGORITHMS (DIJKSTRA), ADVANCED DP, SEGMENT TREES, ETC.

Plan 2

  • Data Structures: Arrays, Strings, Linked Lists, Stacks/Queues, Hash Tables.

  • Algorithms: Binary Search, Basic Sorting (Bubble, Insertion, Merge, Quick).

  • Practice: Solve 5-10 problems/day on platforms like LeetCode or Codeforces.

  • Trees: BST, Heaps, Traversals

  • Graphs: BFS, DFS, Cycle Detection

  • Patterns: Two Pointers, Recursion

  • Dynamic Programming – Knapsack

  • Greedy Algorithms – Activity Selection, Fractional Knapsack

  • Backtracking – N-Queens, Subsets
